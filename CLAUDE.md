# Project Overview

Internal course repository for **Context Engineering for Claude Code** (4-hour course). Holds the catalog, session outlines, Marp slide decks, Mermaid diagrams, instructor demos, and research notes. This is the instructor-only repo; exported artifacts go to students, but this repo does not.

## Directory Layout
- `catalog/`: Course outlines and delivery guides.
- `llm-context/`: Stores context for LLM agents.
- `scripts/`: Export and validation tooling.

## Related Repositories
- [context-claude-companion](https://github.com/kpassoubady/context-claude-companion) — Student hands-on lab repository.
- [context-claude-setup](https://github.com/kpassoubady/context-claude-setup) — Pre-class setup and environment verification.
